# Pioche.IA

Tes opérations bancaires, triées comme un jeu de cartes.

Pioche.IA est une page web autonome : tu importes le relevé CSV de ta banque, tu ranges chaque opération d'un geste (à droite pour valider, à gauche pour corriger, vers le haut pour l'exclure des totaux), puis tu suis tes tendances par catégorie et ton budget du mois.

## Tes données restent chez toi

Rien n'est envoyé sur un serveur. L'état est gardé dans le navigateur et dans un fichier de sauvegarde `.json` que tu enregistres toi-même. Ce dépôt ne contient que le code de l'application.

## Utilisation

- En ligne : ouvre la page GitHub Pages de ce dépôt. Sur iPhone, Safari → Partager → « Sur l'écran d'accueil ».
- Hors ligne : télécharge `index.html` et ouvre-le dans ton navigateur.

Le dossier `exemples/` contient des relevés fictifs pour essayer l'import.
